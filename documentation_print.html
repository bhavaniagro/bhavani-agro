3. SYSTEM ARCHITECTURE & TECH STACK Section 03
ટેકનિકલ આર્કિટેક્ચર, ઇન-મેમરી કેશિંગ અને ક્લાઉડ સિંક્રોનાઇઝેશન

Amar Mine Chems ERP એ હાઇ-પરફોર્મન્સ, સ્કેલેબલ 3-ટાયર ક્લાઉડ આર્કિટેક્ચર પર આધારિત છે. તે મિલીસેકન્ડ રિસ્પોન્સ ટાઇમ અને ક્લાઉડ ખર્ચમાં 85% બચત માટે કસ્ટમ ઇન-મેમરી ડેલ્ટા કેશિંગ એન્જિનનો ઉપયોગ કરે છે:

⚡ સ્માર્ટ ઇન-મેમરી કેશિંગ અને ડેલ્ટા સિંક (Delta Sync Engine)

સામાન્ય રીતે Cloud Firestore માં દરેક વાંચન (Read) માટે ચાર્જ લાગે છે. Amar Mine Chems ના સર્વરમાં apiCacheMiddleware બનાવવામાં આવ્યું છે. જ્યારે યુઝર પહેલી વાર ડેટા માંગે ત્યારે સર્વર Firestore માંથી લાવીને RAM માં મૂકી દે છે. પછીના તમામ યુઝર્સને તે RAM માંથી 0-delay માં મળે છે. જ્યારે કોઈ રેકોર્ડ ઉમેરાય કે બદલાય (POST/PUT/DELETE), ત્યારે કેશ આપમેળે અપડેટ અથવા ક્લિયર થઈ જાય છે. પરિણામે ડેટાબેઝ રીડ ખર્ચમાં 85% નો સીધો ઘટાડો થાય છે.

મુખ્ય કાર્ય: ડીલરો અને ખાતર કંપનીઓનું ડેટાબેઝ.

• સપ્લાયર ગુણવત્તા રેટિંગ (1 થી 5 સ્ટાર) અને હિસ્ટ્રી.

• Purchase Order (PO) જનરેશન: રેટ, ટેક્સ અને ડિલિવરી તારીખ.
• PO સાયકલ: Draft -> Approved -> Issued -> GRN Completed.
• સપ્લાયર્સ સાથે ભાવ સરખામણી અને હિસ્ટોરિકલ ટ્રેકિંગ.
